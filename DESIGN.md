# Subtitle Merge Design Context

## Register
Product UI.

## Visual Language
Film-editing-console, restrained dark workspace, one cool cyan accent, tinted neutrals, precise controls.

## Tokens
- Background: oklch(0.13 0.014 250)
- Panel: oklch(0.18 0.012 250)
- Raised: oklch(0.22 0.014 250)
- Text: oklch(0.94 0.006 250)
- Muted: oklch(0.70 0.018 250)
- Accent: oklch(0.78 0.13 210)
- Success: oklch(0.78 0.13 150)
- Border: color-mix(in oklch, text 14%, transparent)

## Components
- Pill primary buttons, 44px minimum touch target.
- Inputs use a consistent 14px radius and clear focus ring.
- Workbench panels use one radius scale: 22px.
- No nested decorative cards.

## Typography
System UI stack. Product labels stay compact and readable. No display fonts in controls.
