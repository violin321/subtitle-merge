# Subtitle Merge Product Context

register: product

## Product Purpose
Subtitle Merge helps users merge Chinese and English subtitle files into compact, iPhone-friendly ASS bilingual subtitles. It is a focused creator utility, not a marketing landing page.

## Users
- People batch-processing TV or film subtitles.
- Users who care about mobile playback readability, especially iPhone.
- Users who need a quick web tool plus CLI fallback.

## Design Direction
A precise subtitle workbench inspired by editing consoles and playback monitors. The interface should serve the task: load files, tune style, preview mobile/desktop, export ASS.

## Anti-References
- Generic SaaS hero pages.
- Decorative AI-purple gradient landing pages.
- Over-glassy cards and redundant marketing copy.
- Dashboard density that hides the primary flow.

## Product Principles
- The core path should be visible immediately: upload, merge, preview, download.
- Defaults should be trusted and explainable.
- Style controls should be compact, not overwhelming.
- Preview should feel like playback, not decoration.
